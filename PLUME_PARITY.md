# Plume parity ledger

This project targets observable parity with `vuepress-theme-plume@1.0.0-rc.204` at commit `6ea65aa136d870e122f94225896c3cb77caf4984` while keeping Astro as the renderer.

Status meanings:

- `verified`: matched against the frozen source, a rendered reference page, and an automated browser check.
- `implemented`: available, but the full reference matrix is not complete yet.
- `partial`: only part of the Plume contract is available.
- `missing`: not implemented yet.

No row may be marked `verified` from a successful build alone.
