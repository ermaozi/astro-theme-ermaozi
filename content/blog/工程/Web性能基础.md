# 静态站点性能检查清单

静态输出只是起点，页面仍可能因为图片、字体和第三方脚本变慢。

<!-- more -->

## 加载路径

1. 为首屏图片设置准确尺寸，避免布局跳动。
2. 非首屏图片使用懒加载。
3. 只在需要的页面加载图表、评论等大型脚本。
4. 为静态资源设置长期缓存，同时让 HTML 保持可更新。

## 交互与可访问性

- 键盘可以打开菜单、切换标签页并关闭对话框。
- 控件有可读名称和清晰的焦点状态。
- 深色模式不应在首次渲染时闪烁。
- 尊重 `prefers-reduced-motion`。

## 验证

构建检查、浏览器回归和真实部署验证回答的是不同问题。先运行自动化检查，再在目标部署环境确认缓存头和第三方服务。
