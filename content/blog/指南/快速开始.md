# ermaozi 快速开始

只需要 Node.js、pnpm 和一个可以编辑文本的工具，就能开始使用这个主题。

<!-- more -->

## 安装与启动

```bash
pnpm install
pnpm dev
```

`pnpm dev` 会先生成静态页面和 Pagefind 搜索索引，再启动本地预览。

## 修改站点信息

打开 `site.config.mjs`，依次修改域名、站名、作者信息和导航。未配置的评论与互动服务不会加载。

## 新建文章

在 `content/blog/分类名/` 中增加 Markdown 文件，并提供最小 frontmatter：

```yaml
---
title: 我的第一篇文章
description: 用一句话说明文章内容。
permalink: /blog/my-first-post/
createTime: 2026-08-05
tags: [示例]
---
```

完成后运行 `pnpm validate`，检查类型、构建、路由、SEO 和依赖安全。
