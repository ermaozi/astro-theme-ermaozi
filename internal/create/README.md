# create-astro-theme-ermaozi

> 当前为 Beta 测试版，功能和配置可能在后续版本中发生破坏性变化。测试期间建议固定具体版本。

创建并安装一个完整的 `ermaozi` Astro 站点：

```bash
npm create astro-theme-ermaozi@beta
```

不传目录时会启动中文/英文交互式向导，依次设置目录、站名、描述、多语言、默认语言、TypeScript、打包工具、部署方式、Git 和依赖安装。部署方式支持 GitHub Pages、GitLab Pages、Netlify、Vercel、Firebase Hosting 和 Custom，并生成对应平台配置。也可直接传入目标目录，或使用 `--no-install` 只生成文件；初始化器会根据调用方式自动使用 npm、pnpm 或 Yarn。
